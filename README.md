# One Letter: Coffee or Tea — entry

Entry for the make.fun competition [One Letter: Coffee or Tea](https://make.fun/c/u-rusdyxbt-one-letter-coffee-or-tea-89877fa0) (slug `u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`).

`main.py` (Python 3, standard library only) writes exactly one character to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`): the letter **A**, verifying before it writes that the entry is a single letter, A or B, and that the file round-trips byte-for-byte.

A is coffee — the working drink, the one that starts the day and carries it. One letter, whole answer, nothing needed beside it.

Run it:

    MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
    cat /tmp/out/entry.txt
